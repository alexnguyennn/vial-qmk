- flash board with uf2 files that are generated
  - Svalboard uses an RP2040 microcontroller which lets you flash firmware by drag-and-drop to an onboard flash drive.  After loading, it immediately reboots and comes up as a Svalboard, and the flash drive disappears.
Double-tap the RESET button on the bottom of the case to enter bootloader mode.  An “RPI-RP2” flash drive will show up.
You’ll need to flash both sides when updating FW. To do this, each side will need to have its Master port connected to the host PC, in turn.

** Custom keys in vial
- [[https://github.com/svalboard/vial-qmk/blob/vial/keyboards/svalboard/docs/custom_firmware.md#accessing-svalboard-specific-keycodes][svalboard docs]] pointing to use =SV_SAFE_RANGE= only make sense if you don't want to make the key available to bind in Vial/keybard (given the current format of =keymap_support.h=)
  - for some reason =KC_NORMAL_HOLD/KC_FUNC_HOLD= aren't actually declared in vial.json so we can actually bind from =SAFE_RANGE=
- if you do want them bindable in Vial/keybard, you'll need to make sure it's indexed from =QK_KB_0= (see [[https://get.vial.today/docs/custom_keycode.html][vial docs]])
- can't declare a macro to be a custom key alias (e.g. =#define KEY LCTL_T(KC_0)= and then alias =KEY=)

** Custom QSIDs (28, 29) — shift-tap Flow Tap tuning
- =quantum/qmk_settings.{h,c}= add two custom QSIDs beyond upstream Vial's stock set:
  - QSID 28 =flow_tap_shift_delta= (uint16, default 25 ms) — ms to subtract from Flow Tap term for =LSFT_T(KC_V)= and =LSFT_T(KC_M)=
  - QSID 29 =flow_tap_shift_min_clamp= (uint8, default 15 ms) — floor to prevent underflow / negative effective term
- Effect: fast rolls like =space -> M -> S= still get Shift+S because the shift mod-taps use a shorter Flow Tap window than everything else. Chordal Hold still decides opposite-hand disambiguation.
- These QSIDs are invisible in the Vial GUI (its descriptor tops out at QSID 27). Use =tools/vial-qs.py= to inspect/tune them.
*** Adjusting via CLI
 #+begin_src bash
# list all supported QSIDs on the connected keyboard
./tools/vial-qs.py list

# read the current values
./tools/vial-qs.py get 28   # flow_tap_shift_delta
./tools/vial-qs.py get 29   # flow_tap_shift_min_clamp

# tune (values in ms)
./tools/vial-qs.py set 28 40    # bigger delta -> shorter effective term -> shift-taps easier
./tools/vial-qs.py set 29 20    # raise the floor
 #+end_src
- Requires =pip install hid= (cython-hidapi wrapper).
- *Close Vial GUI while scripting.* The GUI caches every QSID at connect time; if you tweak an unrelated slider afterwards it may write back a stale value for these custom fields.
